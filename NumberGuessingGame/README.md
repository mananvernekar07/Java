# 🎯 Number Guessing Game in Java

A simple **Number Guessing Game built using Java**. This beginner-friendly project allows users to guess a randomly generated number and practice the fundamentals of Java programming.

## 📌 About the Project

The program generates a random number, and the player tries to guess it. After each guess, the game provides feedback to help the player determine whether the guessed number is too high or too low.

This project is a great starting point for beginners who want to improve their programming logic and understand how Java works through a practical example.

## ✨ Features

- 🎲 Generates a random number.
- ⌨️ Accepts guesses from the user.
- 💡 Provides hints when a guess is too high or too low.
- 🎉 Notifies the player when the correct number is guessed.
- 🔁 Helps practice interactive programming logic.

## 🛠️ Technologies Used

- **Language:** Java
- **Input:** Java Scanner
- **Random Number Generation:** Java Random class
- **IDE:** Any Java-compatible IDE or text editor

## 📚 Java Concepts Practiced

- Variables and data types
- User input using `Scanner`
- Conditional statements (`if-else`)
- Loops
- Random number generation
- Basic problem-solving and logical thinking

## 🚀 How to Run

### Prerequisites

Make sure the Java Development Kit (JDK) is installed on your system.

Check your Java installation:

```bash
java -version
javac -version
```

### Steps

**1. Clone the repository**

```bash
git clone https://github.com/mananvernekar07/Java.git
```

**2. Navigate to the project folder**

```bash
cd Java/NumberGuessingGame
```

**3. Compile the Java program**

Assuming the source file is named `NumberGuessingGame.java`:

```bash
javac NumberGuessingGame.java
```

**4. Run the game**

```bash
java NumberGuessingGame
```

## 🎮 How to Play

1. Run the program.
2. Enter your guessed number.
3. Follow the hints displayed by the game.
4. Keep guessing until you find the correct number.
5. Enjoy the game!

*The exact gameplay depends on the implementation of the program.*
